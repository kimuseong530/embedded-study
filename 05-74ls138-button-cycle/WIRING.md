# 배선도 — NUCLEO-F401RE + 74LS138

## 1. 구성 요소
- NUCLEO-F401RE (STM32F401RE)
- 74LS138 (3-to-8 디코더, 5V TTL)
- (추후 추가 예정) LED 8개 + 470Ω 이상 저항 8개

## 2. 74LS138 핀맵 (DIP-16, 위에서 본 모습)

```
                +-----U-----+
        A  1 --|1        16|-- VCC (5V)
        B  2 --|2        15|-- Y0
        C  3 --|3        14|-- Y1
       G2A  4 --|4        13|-- Y2
       G2B  5 --|5        12|-- Y3
        G1  6 --|6        11|-- Y4
        Y7  7 --|7        10|-- Y5
       GND  8 --|8         9|-- Y6
                +-----------+
```

(핀 번호는 좌하단부터 시계반대방향으로 1~16, U자 홈이 1번 핀 쪽 표시)

## 3. STM32 ↔ 74LS138 연결표

| 신호 | 74LS138 핀 | STM32 핀 | Nucleo 커넥터 라벨 | 비고 |
|---|---|---|---|---|
| A (LSB) | 1번 | PA10 | D2 | 셀렉트 비트 0 |
| B | 2번 | PB10 | D6 | 셀렉트 비트 1 |
| C (MSB) | 3번 | PA8 | D7 | 셀렉트 비트 2 |
| G2A | 4번 | — | — | **GND에 하드와이어 고정** |
| G2B | 5번 | — | — | **GND에 하드와이어 고정** |
| G1 (출력 허가, active-high) | 6번 | PC7 | D9 | 항상 HIGH 유지 |
| Y7 | 7번 | (미사용) | — | 멀티미터로 측정용, STM32 입력 금지 |
| GND | 8번 | — | GND | Nucleo GND와 공통 |
| Y6 | 9번 | (미사용) | — | 멀티미터로 측정용 |
| Y5 | 10번 | (미사용) | — | 멀티미터로 측정용 |
| Y4 | 11번 | (미사용) | — | 멀티미터로 측정용 |
| Y3 | 12번 | (미사용) | — | 멀티미터로 측정용 |
| Y2 | 13번 | (미사용) | — | 멀티미터로 측정용 |
| Y1 | 14번 | (미사용) | — | 멀티미터로 측정용 |
| Y0 | 15번 | (미사용) | — | 멀티미터로 측정용 |
| VCC | 16번 | — | 5V | Nucleo 5V 핀 |

버튼/LED (보드 내장):
| 신호 | STM32 핀 | 비고 |
|---|---|---|
| B1 (사용자 버튼) | PC13 | 눌림=LOW, 안 눌림=HIGH, 보드 자체 풀업 |
| LD2 (상태 LED) | PA5 | 채널 표시용 (채널번호+1회 깜빡임) |

## 4. 전체 연결 개요 (텍스트 다이어그램)

```
Nucleo 5V  ────────────────────────────► 74LS138 VCC (16)
Nucleo GND ─────┬──────────────────────► 74LS138 GND (8)
                ├──────────────────────► 74LS138 G2A (4)
                └──────────────────────► 74LS138 G2B (5)

PA10 (D2) ──────────────────────────────► 74LS138 A   (1)
PB10 (D6) ──────────────────────────────► 74LS138 B   (2)
PA8  (D7) ──────────────────────────────► 74LS138 C   (3)
PC7  (D9) ──────────────────────────────► 74LS138 G1  (6)

74LS138 Y0~Y7 (15,14,13,12,11,10,9,7) ──► 멀티미터 측정 지점
                                         (추후: 각 Y핀 ── 470Ω 이상 ── LED ── GND)
```

## 5. 주의사항
- **74LS138 출력(Y0~Y7)은 5V 레벨이므로 STM32 GPIO 입력으로 절대 되돌리지 말 것.**
  STM32F401 GPIO는 5V 내성이 없어 손상될 수 있음.
- 출력 전류는 74LS138의 sink 한계(채널당 약 8mA)를 넘지 않도록 할 것.
  LED 추가 시 저항은 **470Ω 이상** 권장
  (5V 공급, LED Vf ≈ 2V 가정 시 (5V-2V)/470Ω ≈ 6.4mA로 8mA 이내).
- G2A, G2B는 소프트웨어로 제어하지 않고 항상 GND에 고정 배선.
- G1은 코드에서 항상 HIGH로 유지 (`DEC_Enable(1)`), LOW가 되면 모든 출력이 비활성(HIGH)됨.

## 6. 확인 절차
1. 위 표대로 배선 후 전원(USB) 연결
2. 멀티미터를 74LS138의 Y0 핀에 대고 시작
3. B1 버튼을 누를 때마다 활성 채널(LOW로 떨어지는 핀)이 Y0 → Y1 → ... → Y7 → Y0 순으로 이동하는지 확인
4. 채널이 바뀔 때마다 보드 내장 LD2가 "채널번호+1"번 짧게 깜빡이는지 확인
   (예: Y0 선택 시 1번, Y7 선택 시 8번)
