# 배선 정리 (NUCLEO-F401RE + 74LS138 + LED 8개 + 버튼 4개)

이 문서는 `Core/Inc/main.h`, `Core/Src/gpio.c`, `.ioc` 설정과 실제 디버깅 과정에서
확인된 물리적 배선을 기준으로 정리한 것입니다. 코드가 바뀌어도 이 핀 배치 자체는
바뀌지 않으니, 나중에 배선을 다시 만지거나 새 보드로 옮길 때 참고용으로 씁니다.

## 1. MCU 핀 전체 목록

| MCU 핀 | 코드 이름 | Arduino 표기 | 모드 | 용도 |
|---|---|---|---|---|
| PB3 | DEC_A | D3 | Output (Push-Pull) | 74LS138 A 입력(1번 핀) 제어 |
| PB5 | DEC_B | D4 | Output (Push-Pull) | 74LS138 B 입력(2번 핀) 제어 |
| PA10 | DEC_C | D2 | Output (Push-Pull) | 74LS138 C 입력(3번 핀) 제어 |
| PB4 | BTN1 | D5 | Input, 내부 Pull-up | 버튼1 (반대쪽 다리 GND) |
| PB10 | BTN2 | D6 | Input, 내부 Pull-up | 버튼2 (반대쪽 다리 GND) |
| PA8 | BTN3 | D7 | Input, 내부 Pull-up | 버튼3 (반대쪽 다리 GND) |
| PA9 | BTN4 | D8 | Input, 내부 Pull-up | 버튼4 (반대쪽 다리 GND) |
| PA2 | USART_TX | D1 (기존 배치) | AF (USART2_TX) | 시리얼 모니터 출력 (ST-Link 가상 COM, 보드 내부에서 이미 연결됨 - 외부 배선 불필요) |
| PA3 | USART_RX | D0 (기존 배치) | AF (USART2_RX) | 시리얼 모니터 입력 (위와 동일, 외부 배선 불필요) |
| PA5 | LD2 | - | Output (Push-Pull) | Nucleo 보드 내장 LED (온보드, 이 프로젝트 로직에서는 사용 안 함) |
| PC13 | B1 | - | Input, EXTI Falling | Nucleo 보드 내장 사용자 버튼 (온보드, 이 프로젝트 로직에서는 사용 안 함 - BTN1~4와 별개) |
| PA13 | TMS | - | SWD (디버거 전용) | ST-Link 디버깅용, 손대지 않음 |
| PA14 | TCK | - | SWD (디버거 전용) | ST-Link 디버깅용, 손대지 않음 |

버튼은 전부 "눌리면 LOW"입니다 (내부 풀업 + 반대쪽 다리 GND 직결).

## 2. 74LS138 (16핀 DIP) 핀별 연결

노치(또는 반원 홈)가 왼쪽을 향하게 놓았을 때, 왼쪽 아래가 1번 핀이고 그 줄이 아래에서 위로 1~8번, 오른쪽 줄이 위에서 아래로 9~16번입니다.

| 74LS138 핀 | 이름 | 방향 | 연결 대상 |
|---|---|---|---|
| 1 | A | 입력 (주소, LSB) | **PB3 (DEC_A)** |
| 2 | B | 입력 (주소) | **PB5 (DEC_B)** |
| 3 | C | 입력 (주소, MSB) | **PA10 (DEC_C)** |
| 4 | G2A | 입력, active-LOW 인에이블 | **GND 직결** |
| 5 | G2B | 입력, active-LOW 인에이블 | **GND 직결** |
| 6 | G1 | 입력, active-HIGH 인에이블 | **VCC(5V) 직결** — MCU가 제어하는 핀 없음 |
| 7 | Y7 | 출력 (active-LOW) | LED 8번째 위치 |
| 8 | GND | - | 보드 GND |
| 9 | Y6 | 출력 (active-LOW) | LED 7번째 위치 |
| 10 | Y5 | 출력 (active-LOW) | LED 6번째 위치 |
| 11 | Y4 | 출력 (active-LOW) | LED 5번째 위치 |
| 12 | Y3 | 출력 (active-LOW) | LED 4번째 위치 |
| 13 | Y2 | 출력 (active-LOW) | LED 3번째 위치 |
| 14 | Y1 | 출력 (active-LOW) | LED 2번째 위치 |
| 15 | Y0 | 출력 (active-LOW) | LED 1번째 위치 |
| 16 | VCC | - | 5V |

**핵심 특징**: G1=HIGH, G2A=LOW, G2B=LOW가 전부 하드웨어적으로 고정되어 있어서
칩은 항상 활성화 상태입니다. 즉 **8개 출력 중 반드시 정확히 하나만 LOW(활성)** 이고,
소프트웨어로 "전부 꺼짐" 상태를 만들 수 없습니다 (인에이블 3핀 중 MCU가 제어하는
핀이 하나도 없기 때문). 이 특성 때문에 모든 버튼 동작은 마지막 LED가 켜진 채로
끝납니다.

Y0~Y6은 15번→9번으로 핀 번호가 내려가고, Y7만 7번 핀입니다 (8번은 GND라 중간에
끼어 있음) — 물리적 핀 번호 순서와 Y 번호 순서가 일치하지 않으니 배선할 때
착각하기 쉬운 부분입니다.

## 3. index ↔ 74LS138 출력 ↔ LED 위치 대응표

코드의 `SetDecoderOutput(index)`가 index(0~7)를 3비트로 나눠 A/B/C에 실어주면, 아래처럼 매핑됩니다.

| index | A(PB3) | B(PB5) | C(PA10) | 활성 출력 | 물리 핀 | LED 위치(1번째부터) |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | Y0 | 15번 | 1번째 |
| 1 | 1 | 0 | 0 | Y1 | 14번 | 2번째 |
| 2 | 0 | 1 | 0 | Y2 | 13번 | 3번째 |
| 3 | 1 | 1 | 0 | Y3 | 12번 | 4번째 |
| 4 | 0 | 0 | 1 | Y4 | 11번 | 5번째 |
| 5 | 1 | 0 | 1 | Y5 | 10번 | 6번째 |
| 6 | 0 | 1 | 1 | Y6 | 9번 | 7번째 |
| 7 | 1 | 1 | 1 | Y7 | 7번 | 8번째 |

지금은 배선이 정상이라 **index = 물리 위치 - 1**로 1:1 대응합니다 (`main.c`의
`LedMappingTest()`로 실측 검증됨).

## 4. LED 배선 (참고 - 정확한 저항값/극성은 실물 기준으로 재확인 권장)

Y 출력이 active-LOW(선택되면 LOW로 싱크)이므로, 각 LED는 **캐소드 쪽이 저항을 거쳐 해당 Y 출력에, 애노드가 VCC 쪽에** 연결되는 구조여야 선택된 Y가 LOW일 때 전류가 흘러 켜집니다. 이 문서 작성 시점에는 실제 저항값이 코드/설정 파일에 남아있지 않아 정확한 값은 표기하지 않았습니다 — 필요하면 실측해서 이 섹션에 추가하는 걸 권장합니다.

## 5. 배선 사고 이력 (참고용)

한 차례 A/B/C 3선이 한 칸씩 밀려 꽂힌 적이 있었습니다:

| 당시 상태 | MCU 핀 | 실제로 꽂혀 있던 74LS138 핀 | 있어야 할 핀 |
|---|---|---|---|
| 오배선 | PB3 (DEC_A) | 2번 (B) | 1번 (A) |
| 오배선 | PB5 (DEC_B) | 3번 (C) | 2번 (B) |
| 오배선 | PA10 (DEC_C) | 1번 (A) | 3번 (C) |

이 때문에 index를 0→7로 순서대로 보내도 LED는 1,3,5,7,2,4,6,8 순서로 튀어 보였습니다
(코드 자체는 정상이었고, 순수 배선 문제였습니다). `main.c`의 BTN3 동작이 바로 이때
관찰된 순서를 그대로 재현한 것입니다. 위 "2. 74LS138 핀별 연결" 표는 이 문제가
고쳐진 **현재 정상 배선**을 기준으로 작성되어 있습니다.
